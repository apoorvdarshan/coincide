# Provider artwork

These files are the providers' own published product icons, retrieved 2026-11-17.
They are used as-is except for the IBM Bob theme variants noted below. A
registry mark without verified colored artwork stays monochrome.

- Amp: [official press kit](https://ampcode.com/press-kit), [app icon](https://ampcode.com/app-icon.svg).
- IBM Bob: [official icon](https://bob.ibm.com/icon.svg?v=1). `bob-light.svg` and `bob-dark.svg` expand the icon's own CSS variables into the exact light and dark values published in that file, so the native SVG renderer can display its gradient and mask.
- CodeBuddy: [official CLI site](https://www.codebuddy.cn/cli/) and its [logo](https://download.codebuddy.cn/web/website/46f66813590b297a89220cdb11f02726dfcc3e26/assets/logo.svg).
- Qwen Code: [desktop logo in the official repository](https://github.com/QwenLM/qwen-code/blob/main/packages/desktop/bootstrap/qwen-code-logo.svg).
- Kiro: [official site icon](https://kiro.dev/icon.svg?fe599162bb293ea0).
- Kilo: [official site icon](https://kilo.ai/favicon/favicon.svg?v=3).
- Gemini CLI: [official site icon](https://geminicli.com/icon.png).
- Kimi Code: [storefront icon in the official repository](https://github.com/MoonshotAI/kimi-code/blob/main/apps/vscode/resources/kimi-icon-storefront.png).

The official Cline, Auggie, and Autohand marks are monochrome; their existing
registry templates use neutral light or dark ink. See [Cline's documentation](https://github.com/cline/cline/blob/main/docs/docs.json), [Auggie's site icon](https://www.augmentcode.com/favicon.svg), and [Autohand's site icon](https://autohand.ai/favicon.svg).
