# Provider branding

These six PNG files are unchanged, byte-for-byte copies of this repository's
`website/public/img/logo-*.png` assets at base commit
`8596e9a`. Keeping the copies beside the desktop crate makes native builds
self-contained under the existing sparse checkout; rendering uses embedded
bytes and performs no network requests.

They identify Codex, Claude, Cursor, Grok, OpenCode and Antigravity. The marks
remain the property of their respective owners. This change does not create
or change a license for those marks. The Swift app also carries its provider
branding in the retired Swift desktop source in Git history.
