免費且開放原始碼 · macOS

所有程式碼代理程式，盡在一款原生 Mac App。

Coincide 在同一個視窗中執行 Claude Code、Codex、Cursor、Grok Build、OpenCode 和 Antigravity。每個代理程式都使用自己的命令列工具，搭配你現有的登入或 API 金鑰；你也可以在對話途中切換代理程式。

下載 Mac 版所有安裝方式

需要搭載 Apple 晶片或 Intel 處理器、執行 macOS 26 或以上版本的 Mac。每個版本都以 Developer ID 簽署並經過 Apple 公證，Coincide 也會自動更新。

從命令列安裝

使用 Homebrew：

brew install --cask apoorvdarshan/tap/coincide

使用 npm（Node.js 18 或以上版本），會檢查下載檔案的總和檢查碼、簽章與公證：

npx coincide-dev

使用你自己的代理程式

至少安裝並登入一個代理程式。Coincide 會在你的 Mac 上啟動該代理程式本身的工具，因此你現有的訂閱方案照常可用。它絕不轉售、代理或計量你的 token。

Coincide 帶來的功能

  • 在對話途中切換代理程式下一個代理程式會收到它錯過的回合摘要，並在同一個資料夾中繼續工作。切換回來時，原本的代理程式會恢復它自己的工作階段。
  • 統一的模型選擇器所有已安裝並登入的代理程式的模型都集中在一個選單中；代理程式支援時，還能選擇推理強度與快速模式。
  • 專案與對話具備搜尋、置頂、封存與延後顯示功能的側邊欄，以及 ⌘K 指令面板。
  • 計畫模式與核准讓代理程式先擬定計畫、逐一核准每個指令與檔案變更，或授予它完整取用權限。
  • 內建 Git差異比對、每個回合的檢查點、工作樹、提交、推送與提取要求。
  • 每個對話都有瀏覽器就在每個對話的終端機旁邊。經你允許後，代理程式可以開啟網頁、閱讀內容並點按瀏覽。
  • 代理程式持續執行結束或更新 Coincide 時，背景主機程序會讓進行中的回合繼續執行。
  • 排程任務與機器人在每個工作日早上九點傳送提示詞，或替機器人設定個性與工作。
  • 電腦控制預設為關閉。開啟後，代理程式可以用自己的游標操作其他 Mac App。
  • 聽寫使用 Apple 的裝置端語音辨識、本機 Whisper 模型，或你自己的 OpenAI 或 Groq 金鑰。
  • 用量儀表板各代理程式方案的用量上限，以及近期回合的本機記錄。
  • coincide 指令代理程式和腳本可以在終端機中建立對話、傳送訊息並等待回覆。
