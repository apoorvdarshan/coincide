Native to Mac

Swift. AppKit. No Electron.

Different coding agents, one native Mac app. A new 10-second motion preview of Coincide.

November 5, 2026 · Apoorv Darshan

Built with Swift and AppKit

Coincide’s Mac interface is built with AppKit, with SwiftUI where it fits, such as Settings. The main window, conversation, composer and agent picker are native Mac UI. The app uses native menus, keyboard shortcuts and accessibility rather than an Electron shell.

That is what the video means by “Swift. AppKit. No Electron.” It is an architectural description, not a benchmark or a promise that every workload will run faster than another app.

Your agents and your existing logins

Claude Code, Codex, Cursor, Grok Build, OpenCode and Antigravity run through their own command-line tools. Coincide uses the logins you already have; it does not sell, proxy or meter tokens. The native interface brings those agents into one place.

The preview shows the Codex, Claude Code and Cursor picker catalogs. Available models depend on the agents installed and signed in on your Mac and on your provider account. Choosing a model also chooses the agent that handles the next turn.

Switch agents. Keep the thread.

When you switch agents mid-thread, the next agent gets a recap of the turns it missed and continues in the same working directory. Each agent keeps its own native session. Switch back, and that agent resumes its session.

The handoff deep dive explains the mechanism and its limits. A shared thread does not mean the providers share their internal state.

About this preview

This is an edited illustrative demo. Conversation text was replaced with generic content for privacy; the picker panels were captured from Coincide. The clip browses provider catalogs, rather than recording a fresh live handoff or simultaneous execution. Model names reflect the captured app state. The motion design and synthesized sound are original.
