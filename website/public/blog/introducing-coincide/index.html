Introducing Coincide

A free, open-source Mac app for the coding agents you already use: Claude Code, Codex, Cursor, Grok Build, OpenCode and Antigravity, side by side in one window.

November 1, 2026 · Apoorv Darshan · Updated November 2, 2026

Coincide runs each agent through its own command-line tool, with the sign-in or API key you already have. Nothing goes through a Coincide server, and nothing is resold. It’s MIT-licensed, and the source is on GitHub.

What it does

  • Switch agents mid-thread. Hand a thread from Claude Code to Codex, or any other agent, and the next one gets a recap of what it missed and keeps going in the same folder. How switching works.
  • Run them at the same time. Projects and threads with search, pinning and archiving, and a ⌘K command palette.
  • Agents keep working after you quit. Turns run in a background agent host.
  • Approve right in the thread. Plan mode, approvals or full access, and questions answered inline.
  • Git built in. Diffs, per-turn checkpoints, worktrees, commits, pushes and pull requests.
  • A terminal and a browser in every thread, which agents can drive when you allow it, with password filling and Bitwarden passkeys.
  • Bots with a personality and a routine, scheduled tasks, Computer Use (off by default), dictation and a usage dashboard.

Install

Download the notarized DMG, or install it from the command line:

brew install --cask apoorvdarshan/tap/coincide
npx coincide-dev

It’s a universal app for Apple silicon and Intel Macs running macOS 26 or later.
