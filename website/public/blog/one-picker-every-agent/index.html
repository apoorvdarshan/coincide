One picker for your coding agents

Keep the conversation in one place, and choose the coding agent and model you want to use next.

November 4, 2026 · Apoorv Darshan

The agent and model are one choice

Click the model button below the composer, or press ⇧⌘M. The picker has a search field, Favorites, and a tab for each agent. Choose a model and you also choose the agent that will handle the next turn.

The clip browses the Codex, Claude Code and Cursor catalogs. Available models come from the agents installed and signed in on your Mac; providers decide which models and limits your account can use. Reasoning effort and speed controls appear where the provider supports them.

Your existing agents and logins

Coincide drives each agent through its own command-line tool, with the login you already have. It does not resell tokens or put the agents behind a Coincide subscription. It is a free, MIT-licensed native Mac app.

The conversation stays together

When you switch agents mid-thread, each provider keeps its own native session. The next agent gets a recap of the turns it missed and continues in the same working directory. The handoff deep dive explains that boundary in more detail.
