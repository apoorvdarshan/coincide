Build Coincide from source

Coincide's desktop application is being developed in Rust. The iPhone and iPad companion remains a separate iOS project.

Updated November 1, 2026

Rust desktop

Install a Rust toolchain and the native dependencies for your platform. On macOS, install the Xcode command-line tools. The repository's Rust CI workflow lists Linux and Windows dependencies.

git clone https://github.com/apoorvdarshan/coincide.git
cd coincide
cargo build -p coincide-desktop --bin coincide-rust --locked
cargo test -p coincide-core --locked

The Rust desktop is in development; platform acceptance and feature parity are still being verified. The repository's Rust status and packaging notes describe the current checks and limits.

The existing public download, Homebrew cask and npm installer contain the retired Swift Mac app. They do not install the Rust desktop. A Rust release pipeline is not configured yet.

Coincide Remote for iPhone and iPad

The iOS companion remains in the repository. With Xcode and XcodeGen installed, generate its project using xcodegen generate --spec project-remote.yml. See the companion's setup. Compatibility with the Rust desktop is still being mapped and verified.
