macOS permissions

Coincide asks for a permission only when you use a feature that needs it. Most people never see more than one or two of these prompts. This page lists them all, so you know why each one appears and where to change your answer.

Updated November 1, 2026

The permissions

PermissionAsked for whenWhere to change it
MicrophoneYou dictate a message the first time (dictation)System Settings › Privacy & Security › Microphone
Speech RecognitionYou dictate with Apple’s speech recognition, the default enginePrivacy & Security › Speech Recognition
AccessibilityYou turn on Computer Use, or Appshots with both ⌘ keys or the window’s textPrivacy & Security › Accessibility
Screen RecordingYou turn on Computer Use or Appshots, which capture windowsPrivacy & Security › Screen & System Audio Recording
Automation (Apple Events)Computer Use’s helper controls another app for an agentPrivacy & Security › Automation
Full Disk AccessYou import from a browser whose data macOS protects, such as Safari, in Settings › Browser › ImportPrivacy & Security › Full Disk Access
Keychain accessYou import cookies from a Chromium browser (macOS asks to allow that browser’s Safe Storage key), or allow Coincide to read Cursor’s sign-in for usage limitsAnswered per prompt; Keychain Access app
NotificationsCoincide first notifies you that a turn finished or needs youSystem Settings › Notifications › Coincide
Local NetworkYou turn on Coincide Remote (coming soon to the App Store) so a phone or iPad can connectPrivacy & Security › Local Network
Allow in the Background (Login Items)The background agent host starts, or you turn on Keep AwakeSystem Settings › General › Login Items & Extensions
Administrator passwordYou turn Keep Awake on or off (it runs pmset)Asked each time

Settings › Computer Use and Settings › Appshots show the status of the permissions they need, with buttons that open the right System Settings pane. Grant the permission there, come back, and the status refreshes.

Background items

Three of Coincide’s parts run on their own, so macOS lists them under Login Items & Extensions › Allow in the Background:

  • The agent host, which keeps agents running after you quit Coincide (Settings › General › Agents › Keep agents running when Coincide quits). If you turn Coincide off there, Settings says “Coincide is turned off under Allow in the Background in Login Items. Turn it on to keep agents running after Coincide quits.” and offers Open Login Items…. Until then, agents run inside the app and stop when it quits. See Background agents.
  • The lid watcher, which Keep Awake starts at login while it’s on, to follow the lid. If it isn’t allowed, Settings says “Allow Coincide in Login Items to watch the lid”.
  • The battery helper, a small launchd daemon that runs as root only while Sleep normally on battery and Keep Awake are on. It takes no input and only switches sleep on or off when the Mac is plugged in or unplugged. Until you allow it, the Mac stays awake on battery too.

Turning these features off in Coincide unregisters their background items.

Why the prompts come back for some builds

macOS ties privacy permissions to an app’s code signature. Releases are signed with Coincide’s Developer ID, so your answers last across updates. Builds you make from source are signed ad hoc by default, and each new build looks like a different app, so macOS asks again. Sign your own builds with a stable identity to avoid that (see Build from source).

Taking a permission back

Turn it off in the pane listed above. The feature that needs it stops working until you allow it again: dictation can’t hear you, Computer Use and Appshots stop seeing windows, and so on. Turning the feature itself off in Coincide is usually simpler: Computer Use ends agents’ access when you turn it off or quit Coincide. What each feature sends and where is in the privacy policy.
