A tour of Settings

Open Settings with ⌘,. The sidebar lists the panes, then a page for each agent under Providers, then About. The search field at the top of the sidebar finds panes, agents and individual settings by name or keyword, such as “dark mode” or “steer”.

General

The longest pane, in sections. Restore Defaults… at the bottom resets them, keeping your providers, custom models and default model.

SectionWhat’s in it
(top)Appearance (light, dark or system), number format, font size, reply font, which side your messages sit on, dark and light themes, the pointing hand over clickable items, where the terminal opens (below the chat or on the right), its GPU rendering and translucency, and which app opens project folders
ChatSend messages with Return or Command-Return; follow-up behavior while an agent works (Steer, Queue or Interrupt); show reasoning; open links in your default browser; confirm before deleting or archiving threads; hold ⌘Q to quit; resume after usage limits
New ThreadsThe default agent, model and effort, access (Full access or Ask for approval), whether New Thread starts a chat, and whether the agent names threads and keeps their titles up to date
NotificationsWhether Coincide notifies you when a turn finishes or needs you while it’s in the background
GitCreate checkpoints before each turn, and the branch prefix for worktrees (coincide/ by default)
AgentsClose idle agents after a while, keep agents running when Coincide quits (the background agent host), and whether schedules agents create need your approval
Keep AwakeKeep this Mac awake 24/7, sleep normally on battery, and the lid options
RemoteAllow Coincide Remote, the iPhone and iPad companion (coming soon), with its port, Bonjour name and paired devices
Command LineCommand-line control, and where the coincide command is installed for Terminal

More on Keep Awake, Background agents and Notifications.

Models

Every model your agents offer, in one list you can filter. Star favorites, hide models you never use from the picker, choose Use for New Threads, copy a model’s ID, or Add Custom Model with an ID the agent’s CLI accepts but doesn’t list. See Model picker.

Usage

Plan limits per account, and the tokens your agents used on this Mac: tokens and estimated cost per day over the last 7, 30 or 90 days, with the top models and projects. Options: show usage in the menu bar, include Claude Code and Codex sessions you ran in a terminal or another app, read figures from provider websites through your sign-in in Coincide’s browser (off by default), and check Anthropic API-key rate limits on request. See Usage dashboard.

Instructions

The global instruction files every agent reads in every project, such as AGENTS.md and CLAUDE.md, with an editor, Use one file for all agents (links the others to one master file) and sync of that master to iCloud Drive or a Git repository. A project’s own instructions open with File › Edit Instructions…. See Instruction files.

Archive and Keyboard

Archive lists threads you archived, with a filter, Unarchive and Delete. Keyboard lists every command’s shortcut, lets you record new ones, warns about conflicts, and shows the keys each part of the window uses. See Keyboard shortcuts.

Voice

Dictation: the engine (Apple’s speech recognition on the Mac, a local Whisper model, or OpenAI or Groq with your own key), the language, the microphone and its level, a keyboard shortcut (off by default), and Send when I stop. Whisper models download here, from Hugging Face, only when you click Download. If Codex is signed in with an API key, Use Codex’s Key… copies it for OpenAI dictation. See Dictation.

Browser

The browser in each thread: the shared profile or private per-thread sessions, the search engine for the address bar, Agent Control in new threads, importing cookies, history and bookmarks from other browsers, clearing history or cookies and site data, and bookmarks. Its Passwords section connects 1Password and Bitwarden through their command-line tools, offers to save logins in your Keychain, imports passwords from a CSV export, lists the sites agents may sign in to, and turns on passkeys from Bitwarden. See Browser in every thread and Passwords and logins.

Computer Use and Appshots

Computer Use (off by default) lets agents see and operate other Mac apps. The pane shows the permissions it needs, the driver’s status and version, which threads are using the Mac, and whether to show the agent’s cursor. Appshots (off by default) captures the window you’re working in into a chat with both ⌘ keys or a shortcut, optionally with the window’s text and a sound. See Computer Use and Appshots.

Providers

Overview lists each agent with a switch to use it. Each agent then has its own page:

  • Use agent, which offers its models in the picker and lets threads run it;
  • Executable: a custom path, or empty to search your shell’s PATH, and Check Again;
  • Details: version, account and location;
  • Accounts: extra logins or API keys (how accounts work);
  • Usage Limits: for Cursor, whether Coincide may read its sign-in from the Keychain to show your limits;
  • Models: custom model IDs;
  • Environment Variables added on top of your login shell’s;
  • Setup: the install and sign-in commands, with Run in Terminal.

Antigravity’s page also installs Google’s runtime, signs you in with Google and shows the account-risk notice. Each agent’s page on this site explains the details: Agents.

About

Coincide’s version and build, App Updates (check for updates daily, which is on by default, Check for Updates…, Download Update and Install on Quit), links to get help, report bugs, request features and follow the project, and the acknowledgements and licenses of T3 Code, SwiftTerm, Cua Driver, WhisperKit and macbook-24x7-agents. See Updating.
