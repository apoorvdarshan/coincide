Uninstall Coincide

Deleting Coincide.app removes the app. To remove everything it set up, do a few things in Coincide first, then delete its files. Your agents’ own command-line tools, their sign-ins and your projects are never touched.

Updated November 1, 2026

Turn off Keep Awake before you delete Coincide. While it’s on, your Mac’s sleep is disabled with pmset. Turning it off in Coincide puts back the exact sleep settings you had before. If you delete the app first, the Mac stays unable to sleep until you fix it by hand (see below).

Before you delete the app

Open Coincide and, in Settings › General:

  1. Under Keep Awake, turn off Keep this Mac awake 24/7. Coincide asks for your password, restores your sleep settings and removes the lid watcher and, if you used Sleep normally on battery, the battery helper that runs as root.
  2. Under Agents, turn off Keep agents running when Coincide quits. Agents still running in the background agent host finish there; once nothing runs, the host exits and is unregistered.
  3. Let running turns finish, then quit Coincide.

If you paired a device with Coincide Remote, you can also turn off Allow Coincide Remote under Remote.

With Homebrew

If you installed with Homebrew, it quits Coincide, unloads its three background jobs (the agent host, the lid watcher and the battery helper) and removes the app, the old copies the updater kept and the coincide command link:

brew uninstall --cask coincide

Add --zap to also delete its data, caches, preferences, browser storage and Keychain items, everything listed in Data and settings except ~/.coincide/worktrees, ~/Downloads/Coincide and an iCloud Drive copy:

brew uninstall --zap --cask coincide

The worktrees stay because they can hold work you haven’t committed or pushed, and ~/.coincide goes only once it’s empty.

By hand

  1. Quit Coincide and drag Coincide.app from Applications to the Trash.
  2. Remove old copies the updater kept: hidden .Coincide-backup-…app folders next to the app (ls -a /Applications | grep Coincide lists them).
  3. Remove the coincide command. Coincide linked it into one of /opt/homebrew/bin, /usr/local/bin or ~/.local/bin. This removes the link only if it points into Coincide.app:
tool=$(command -v coincide) && readlink "$tool" | grep -q 'Coincide.app/Contents/Helpers/coincide' && rm "$tool"

Then check System Settings › General › Login Items & Extensions: nothing from Coincide should be left under Allow in the Background. If a background job is still loaded because the app was deleted while it ran, unload it:

launchctl bootout gui/$(id -u)/com.apoorvdarshan.coincide.agent-host
launchctl bootout gui/$(id -u)/com.apoorvdarshan.coincide.always-on
sudo launchctl bootout system/com.apoorvdarshan.coincide.power-helper

Each line fails harmlessly when that job isn’t loaded.

Data and settings

Delete these to remove Coincide’s data. Back up anything you want to keep first, such as transcripts in the data folder.

LocationWhat’s there
~/Library/Application Support/CoincideProjects, threads and transcripts, attachments, bots, schedules, settings, checkpoints, usage history, the agent host’s logs, sign-in folders of extra agent accounts, imported CLI sessions, browser history and bookmarks, Whisper models and the Antigravity runtime Coincide downloaded
~/.coincide/worktreesGit worktrees Coincide created for threads. They can hold work you haven’t committed or pushed; check them before deleting, and remove them with git worktree remove from the project so git forgets them too
~/Library/Caches/com.apoorvdarshan.coincideUpdates while they download and are checked
~/Library/WebKit/com.apoorvdarshan.coincide, ~/Library/HTTPStorages/com.apoorvdarshan.coincideThe browser’s profile: cookies, sign-ins and site data
~/Library/Preferences/com.apoorvdarshan.coincide.plist, ~/Library/Preferences/com.apoorvdarshan.coincide.agent-host.plistPreferences of the app and of the agent host
~/Library/Saved Application State/com.apoorvdarshan.coincide.savedStateWindow state macOS keeps
~/Downloads/CoincideFiles downloaded in Coincide’s browser (yours; keep what you need)
iCloud Drive › Coincide › InstructionsOnly if you synced an instruction file there; it stays when you turn sync off

If you started Coincide with COINCIDE_DATA_DIR, its data and worktrees are in that folder instead. Coincide Debug, built from source, keeps its own data in ~/Library/Application Support/Coincide Debug. More detail in Where data is stored.

Not Coincide’s: your agents’ own files, such as ~/.claude, ~/.codex or ~/.grok, and the agent tools themselves. Uninstall those with each tool’s own instructions if you want them gone too.

Keychain items

Coincide keeps secrets in your login Keychain: API keys for extra agent accounts and for dictation, passwords and one-time-code secrets of logins you saved, your Bitwarden session if you connected Bitwarden, and Coincide Remote’s certificate and key. brew uninstall --zap removes them. Otherwise, this removes every password item Coincide created, then Coincide Remote’s certificate and private key:

for service in provider-account voice browser browser-logins remote; do
  while security delete-generic-password -s "com.apoorvdarshan.coincide.$service" >/dev/null 2>&1; do :; done
done
security delete-identity -c "Coincide Remote"

If you already deleted it

If Keep Awake was on when you deleted Coincide, your Mac’s sleep is still disabled. Turn it back on with:

sudo pmset -a disablesleep 0

Keep Awake also set the Mac never to sleep on the charger. pmset -g shows the current values; set your preferred sleep timing again in System Settings.
