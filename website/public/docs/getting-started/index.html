Getting started

Coincide runs the coding agents you already use. You bring at least one agent’s command-line tool and your sign-in; Coincide gives them one window, one model picker and threads you can hand from one agent to another. This guide takes you from download to a first finished turn.

Updated November 1, 2026

1. Install Coincide

Coincide runs on macOS 26 or later, on Apple silicon and Intel Macs. Download the DMG and drag Coincide to Applications, or install from Terminal:

brew install --cask apoorvdarshan/tap/coincide
npx coincide-dev

Every release is signed with Developer ID and notarized by Apple. All the options, with system requirements, are on the download page.

2. Install and sign in to an agent

Coincide doesn’t provide models. It starts each agent’s own tool with the sign-in or API key you already have, so your subscriptions keep working and nothing is routed through anyone else. Install at least one and sign in once in Terminal:

  • Claude Code: claude auth login
  • Codex: codex login
  • Cursor: cursor-agent login
  • Grok Build: grok login
  • OpenCode: opencode auth login
  • Antigravity: set up inside Coincide, in Settings › Antigravity (read its account-risk notice first)

Each agent’s page in Settings (⌘,, then the agent under Providers) shows its install and sign-in commands with a Run in Terminal button, and whether Coincide found it. If you installed an agent while Coincide was open, click Check Again. If the composer shows Set Up a Provider, no agent is ready yet; troubleshooting covers the usual causes.

3. Add a project

A project is a folder on your Mac, usually a git repository. Choose File › Add Project… (⇧⌘O) and pick the folder, or open the command palette with ⌘K and type a path starting with / or ~. The project appears in the sidebar.

Not everything needs a project. File › New Chat (⇧⌘N) starts a chat with no folder of yours, for questions and research.

4. Start a thread

With the project selected, press ⌘N for a new thread. Before you type, look at the controls under the message field:

  • Agent and model (⇧⌘M): every installed, signed-in agent’s models in one menu, grouped by agent. Star the ones you use. See Model picker.
  • Reasoning effort (⇧⌘E), where the model offers levels.
  • Access (⇧⌘A): Full access lets the agent run commands and edit files without asking, and is the default for new threads. Ask for approval stops at each command or file change for you to allow it. Change the default in Settings › General › New Threads. See Approvals and questions.
  • Build or Plan (⇧⇥): in plan mode the agent investigates and proposes a plan instead of changing files. See Plan mode.
  • Below the field: whether the thread works in your Local checkout or a worktree of its own, and the branch.

Type what you want and press Return. The reply streams in, with the agent’s commands and file changes folded into a work log you can expand. Type @ to mention a file and / for commands, or drop in images and files.

5. While it works

  • Send another message to steer the running turn (Claude Code, Codex and OpenCode) or queue it for afterwards. ⌘↩ does the other one.
  • Answer the agent’s questions and approval requests where Coincide shows them, right in the thread.
  • Press ⌘. to stop the turn.
  • Open the diff with ⌘D to review what changed, or the terminal with ⌘J.
  • Start another thread, on another agent if you like. Threads run at the same time; the sidebar shows which are working and which need you. Coincide notifies you when a turn finishes or needs you while it’s in the background.

You can quit Coincide while agents work: by default they keep running in its background agent host, and Coincide catches up when you open it.

6. Try switching agents

Open the model picker in the same thread and choose another agent’s model. The next message goes to that agent, with a recap of the turns it missed, in the same folder. Switch back later and the first agent resumes its own session. See Switch agents mid-thread.
