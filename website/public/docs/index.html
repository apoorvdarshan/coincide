Docs

Coincide documentation

How to install Coincide, connect your agents and get the most out of it, with reference pages for every shortcut, command and setting.

Start here

  • Getting startedInstall Coincide, connect an agent, add a project and run your first thread, in about ten minutes.
  • DownloadThe notarized DMG, Homebrew or npm, with system requirements, updates and uninstalling.
  • UpdatingHow the in-app updater checks, verifies and installs new releases, and how Homebrew and npx installs update.
  • UninstallTurn off Keep Awake first, then remove the app, its helpers, the coincide command, its data and its Keychain items.

Reference

  • Keyboard shortcutsEvery default shortcut, the keys each part of the window handles, and how to record your own in Settings › Keyboard.
  • Command-line referenceEvery coincide command, option, output format and exit status, with the rules for naming threads and projects.
  • Settings tourWhat each pane of the Settings window holds, from General and Models to each agent’s page and About.
  • Environment variablesVariables Coincide reads, the ones it gives agents, terminals and scripts, and those it sets for each agent account.

Guides

  • Accounts and API keysAdd a second subscription login or an API key to any agent, pick it per thread, and see where each key is kept.
  • Import CLI sessionsTurn Claude Code and Codex conversations from Terminal into Coincide threads that resume the same native session.
  • Rich agent outputHow agents show images, audio, video and sandboxed interactive HTML or SVG previews in a thread, and the limits.
  • Where data is storedEvery folder and Keychain item Coincide uses on your Mac, what’s in each, and how to move, back up or reset them.
  • macOS permissionsEach macOS permission Coincide can ask for, which feature needs it, and how to grant or take it back.
  • TroubleshootingWhat Coincide’s error messages mean and how to fix them: missing or signed-out agents, updates, Gatekeeper and more.

Contributing

  • Build from sourceBuild the Rust desktop, run its core tests and find the iOS companion project.
  • TranslationsThe 19 languages, how to switch Coincide’s language, and how to report or fix a translation with the catalog tools.

More help

Answers to common questions are in the FAQ, and what changed in each release is in the changelog. For anything else, ask in the Coincide Discord or open an issue on GitHub. The source code is the final reference: github.com/apoorvdarshan/coincide.
