Composer

The composer’s keys follow two settings in Settings › General › Chat: Send messages with (Return, the default, or Command-Return) and Follow-up behavior (Steer, the default, Queue or Interrupt). With the defaults:

KeysWhat they do
↩Send the message, or steer the agent with it while it works
⌘↩Queue the message for after the turn instead
⇧⌘↩Send the first queued message into the current turn
⇧↩Insert a new line
⇧⇥Switch between Build and Plan
↑ / ↓Earlier and later messages you sent
⌥↑Edit the last queued message
⇥Insert the highlighted file or command
⎋Close file and command suggestions (and cancel dictation)

With Command-Return, ⌘↩ sends, ⇧⌘↩ does the other follow-up, and ↩ inserts a new line. With Queue, the roles of steering and queueing swap. Type @ to mention a file and / for commands. Steering works with Claude Code, Codex and OpenCode; for the other agents a steered message waits in the queue.

Shortcuts set elsewhere

  • Appshots: press the left and right ⌘ keys together in any app, or record your own shortcut, in Settings › Appshots. See Appshots.
  • Dictation: off by default. Turn on a keyboard shortcut in Settings › Voice: a key with ⌘, ⌃ or ⌥, one modifier pressed on its own, or the 🌐 fn key, held or tapped. It works while a Coincide window is in front. See Dictation.

Changing shortcuts

  1. Open Settings › Keyboard. Filter by a command’s name or keys, or turn on Show only conflicts.
  2. Click a command’s shortcut and type the new one. Escape cancels; Delete removes the shortcut. Shortcuts need ⌘ or ⌃, so they never take keys away from text fields.
  3. Read the notes under the row. Coincide tells you when a shortcut is “Also assigned to” another command, when macOS uses it, when it would take a key from the composer, or when a standard menu item keeps it (then your command gets no shortcut). It also notes keys a focused terminal keeps for itself.

Reset All… puts every menu command back to its default. App Shortcuts you add for Coincide in System Settings › Keyboard › Keyboard Shortcuts take priority over Coincide’s own; the pane links there with Open Keyboard Settings….
