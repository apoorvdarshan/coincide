Where Coincide keeps your data

Coincide has no account and no server. Everything it keeps stays on your Mac, in the places below. Your agents’ command-line tools keep their own files, which Coincide doesn’t manage.

Updated November 1, 2026

On this page

  2. Other folders
  3. The Keychain

  5. Moving, backing up and resetting

The data folder

Coincide’s main folder is ~/Library/Application Support/Coincide, unless you set COINCIDE_DATA_DIR (see below). It holds:

InsideWhat it is
projects.json, threads/, thread-index.jsonYour projects, and each thread’s transcript. The sidebar loads from the small index; a transcript is read only when you open the thread.
attachments/Images and files you attach, and images agents generate, copied here so they outlive the agent’s scratch folders
checkpoints/Snapshots of a project’s working tree taken before each turn (Settings › General › Git › Create checkpoints), used to review or revert what a turn changed
Chats/The working folder of chats that have no project
bots.json, scheduled-tasks.jsonYour bots and your scheduled tasks
settings.json, ui-state.jsonSettings and what the window last showed
usage-history.jsonUsage history of the latest 10,000 finished turns, for Settings › Usage
agent-host/The background agent host’s event logs, session locks and the copy of its own files it runs from
providers/Sign-in folders of agent accounts you add besides the default one, and Antigravity’s profile
tools/The Antigravity runtime Coincide downloads from Google
ImportedSessions/Exact copies of CLI sessions you imported
browser-library.json, browser-logins.jsonBrowser history and bookmarks, and the list of logins you saved, without their passwords
Voice/Whisper models you downloaded for dictation
remote.jsonCoincide Remote settings
control.sockThe socket the coincide command talks to, while Command-line control is on

Coincide writes threads as they change and loads a transcript only when you open its thread, so long histories stay quick.

Other folders

LocationWhat it is
~/.coincide/worktreesGit worktrees Coincide creates when a thread runs in a worktree of its own. They’re real checkouts and can hold uncommitted work.
~/Library/WebKit/com.apoorvdarshan.coincide, ~/Library/HTTPStorages/com.apoorvdarshan.coincideThe browser’s shared profile: cookies, sign-ins and site data. Settings › Browser › Browsing data clears it.
~/Library/Caches/com.apoorvdarshan.coincideApp updates while they’re downloaded and checked
~/Downloads/CoincideFiles downloaded in Coincide’s browser, each in a folder of its own
~/Library/Preferences/com.apoorvdarshan.coincide.plistA few app preferences, such as whether the agent host is on
iCloud Drive › Coincide › InstructionsA copy of your instruction file, only if you turn on iCloud sync in Settings › Instructions

The Keychain

Secrets never go in the data folder. They’re in your login Keychain:

  • API keys of agent accounts you add, one item each, labelled “Coincide: account name” (service com.apoorvdarshan.coincide.provider-account), and an optional Anthropic Admin API key beside it;
  • OpenAI and Groq API keys for dictation (…coincide.voice);
  • passwords and one-time-code secrets of logins you save (…coincide.browser-logins) and your Bitwarden session if you connect Bitwarden (…coincide.browser);
  • a hash of each device paired with Coincide Remote (…coincide.remote), and Remote’s certificate and private key, both labelled “Coincide Remote”.

Coincide passes a key only to the program or service it belongs to, in an environment variable or a request header. See Accounts and API keys.

Your agents’ own files

Each agent tool keeps its own sign-in, settings and history where it always does, for example ~/.claude for Claude Code, ~/.codex for Codex and ~/.grok for Grok Build. Coincide reads some of them (to show your account, import sessions or read usage) but doesn’t move or delete them. Extra accounts you add in Coincide get their own copies of these folders under providers/ instead.

Moving, backing up and resetting

A different data folder

Start Coincide with COINCIDE_DATA_DIR set to use another folder for its data, its worktrees and Antigravity’s profile. It’s meant for testing; your Keychain items and browser profile stay the same. From Terminal:

COINCIDE_DATA_DIR=~/coincide-scratch /Applications/Coincide.app/Contents/MacOS/Coincide

Builds of Coincide Debug, made from source, use ~/Library/Application Support/Coincide Debug and their own Keychain items, background jobs and permissions, so they never touch your installed copy’s data.

Backups

Time Machine and other backups of your home folder include these folders and may include your Keychain. Quit Coincide before copying the data folder by hand, so nothing is mid-write.

Starting fresh

Quit Coincide, then move ~/Library/Application Support/Coincide to the Trash. Coincide starts empty the next time, while your agents stay signed in through their own tools. To clear only the browser, use Settings › Browser › Browsing data. To remove everything, follow Uninstall.

What leaves your Mac, and when, is described in the privacy policy.
