OpenCode in Coincide

OpenCode is an open-source coding agent that works with many model providers. Coincide runs its local server on your Mac and shows its sessions as native threads, with your OpenCode providers and keys.

How Coincide runs OpenCode

Coincide starts its own opencode serve on 127.0.0.1, on a random port and with a random password, and talks to it over OpenCode’s HTTP API. OpenCode then calls the model providers you connected to it. The server listens only on your Mac and is shared by Coincide’s OpenCode threads.

Coincide needs OpenCode 2 or later; with an older version it asks you to run opencode upgrade. It finds opencode on your shell’s PATH, in ~/.opencode/bin and the usual install folders, or at a custom path set in Settings › OpenCode.

Set it up

  1. Install OpenCode (see opencode.ai for other ways):
    curl -fsSL https://opencode.ai/install | bash
  2. Connect a provider, such as OpenCode Zen or your own provider account:
    opencode auth login
  3. Open Settings › OpenCode and choose Check Again. Coincide treats OpenCode as ready once its server lists at least one model.
  4. Choose an OpenCode model in the composer, or type /opencode to move the current thread to OpenCode.

In Settings › OpenCode you can also add accounts. A login account gets its own OpenCode data folder (XDG_DATA_HOME) and its own opencode auth login. An API-key account can use OpenCode Zen, Anthropic, OpenAI, OpenRouter, Gemini, xAI, Groq, DeepSeek or Mistral, with the key kept in your Keychain. Agent accounts explains the options.

Models

Models come from OpenCode’s server as provider/model IDs, so every model from every provider you connected shows up in Coincide’s model picker. Where a model has reasoning variants, Coincide offers them as reasoning effort. OpenCode models have no fast mode option.

What works with OpenCode

In CoincideWith OpenCode
Plan modeUses OpenCode’s own plan agent, with file edits denied while planning.
ApprovalsAsk for approval asks before shell commands, file edits and access outside the project folder.
Full accessAllows everything and answers any remaining permission requests automatically.
QuestionsOpenCode’s forms are shown inline. Forms with links or hidden or conditional fields are declined, and OpenCode is told why.
SteeringMessages sent while OpenCode works steer the running turn.
AttachmentsImages are sent to OpenCode as files; other files are mentioned by path.
SubagentsOpenCode’s subagent tasks and their child sessions are followed in the turn.
ResumingEach thread reloads its own OpenCode session, and Coincide keeps the session’s title in step with the thread’s.
Usage limitsOpenCode Go plan windows, read with the key OpenCode stores. Your OpenCode Zen balance is available as an opt-in reading from the OpenCode Console in Settings › Usage.

Why use OpenCode in Coincide

OpenCode lets one agent reach many providers, including ones the other agents don’t cover, such as OpenRouter, Groq, DeepSeek or Mistral. In Coincide those models sit in the same picker as Claude Code’s and Codex’s, and you can switch a thread between OpenCode and another agent when one of them is a better fit for the next step.

Limitations

  • OpenCode 1.x isn’t supported.
  • Some OpenCode form types aren’t supported and are declined.
  • Earlier OpenCode sessions can’t be imported; importing works for Claude Code and Codex.
  • Bot personalities are sent with the first message rather than as a system prompt.
