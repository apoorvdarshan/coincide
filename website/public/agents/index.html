Agents

Bring your own agents

Coincide doesn’t provide AI models. It starts each agent’s own command-line tool on your Mac, with the sign-in or API key you already set up, so your existing subscriptions keep working. Nothing is resold, proxied or metered.

  • Claude CodeAnthropic’s agent through its own CLI, with your Claude plan or API key. Plan mode, steering, subagents and fast mode.
  • CodexOpenAI’s agent through codex app-server, with your ChatGPT sign-in or API key. Plan mode, steering and speed tiers.
  • CursorCursor’s command-line agent over the Agent Client Protocol, with your Cursor login or API key, and plan mode.
  • Grok BuildxAI’s agent through the grok CLI over ACP, with your Grok login or an xAI API key, and its usage limits.
  • OpenCodeThe open-source agent through its local server, with any model provider you connect to OpenCode, and steering.
  • AntigravityGoogle’s agent through its own ACP runtime, which Coincide downloads and verifies. Read the account-risk note first.

How it works

Install and sign in to at least one agent the way its maker describes, then open Coincide. Coincide finds each agent’s executable on your login shell’s PATH (or at a path you choose in Settings), checks whether you’re signed in, and lists its models in one model picker. Each agent keeps its own configuration and instruction files, such as CLAUDE.md or AGENTS.md, because Coincide runs the same tool you’d run in Terminal.

A thread isn’t tied to one agent. Type /claude, /codex, /cursor, /grok, /opencode or /antigravity in the composer, or pick another agent’s model, and the next agent gets a recap of the turns it missed. Switching agents explains the recap.

“ACP” is the Agent Client Protocol, an open protocol for connecting coding agents to apps. Every agent supports approvals or full access, inline questions, image attachments where its model accepts images, resuming its own session in each thread, and running in Coincide’s background agent host.

Choosing an agent

You don’t have to choose one. Keep several signed in and pick per task, for example one agent to plan or review, another to implement, another for a second opinion. Coincide’s usage dashboard shows how much of each plan you’ve used, which helps when one agent is close to its limit.

Antigravity is the exception to “just sign in”: Google’s terms restrict third-party tools, so read the account risk before using a Google subscription with it.
