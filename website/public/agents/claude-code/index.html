Claude Code in Coincide

Coincide runs the claude command-line tool you already have installed, signed in with your own Claude plan or Anthropic API key, and gives it a native Mac window, threads, git tools and a browser. You can hand any thread to another agent and back.

How Coincide runs Claude Code

Coincide starts claude and talks to it over Claude Code’s stream-json control protocol, the same one Anthropic’s Agent SDK uses. Nothing goes through a Coincide server: Claude Code talks to Anthropic (or to the Bedrock, Vertex AI or gateway endpoint it’s configured for) exactly as it does in Terminal. Coincide never resells, proxies or meters your tokens.

Coincide looks for claude on your login shell’s PATH and in the usual install folders, such as Homebrew’s and ~/.local/bin. If yours lives elsewhere, set a custom path in Settings › Claude Code. Your own Claude Code configuration, CLAUDE.md files and settings keep applying, because it’s the same tool.

Turns run in Coincide’s background agent host, so a long Claude Code turn keeps going when you quit or update Coincide.

Set it up

  1. Install Claude Code with Anthropic’s installer (see the official Claude Code page for other ways):
    curl -fsSL https://claude.ai/install.sh | bash
  2. Sign in with your Claude account, or set up an API key:
    claude auth login
  3. Open Settings › Claude Code in Coincide. It shows whether Claude Code is installed and signed in, its version and account, and can run both commands in Terminal for you. Choose Check Again after signing in.
  4. Pick a Claude model in the composer’s model picker and send your first message.

To use more than one Claude account, or an Anthropic API key next to your subscription, add accounts in the same pane. Each login account gets its own Claude Code configuration folder, and API keys are kept in your Keychain. Agent accounts explains how.

Models, effort and fast mode

The model list comes from Claude Code itself, so it matches what your account can use, filled in with details Coincide knows about each model. If a model needs a newer Claude Code than you have, Coincide says which version to upgrade to.

  • Reasoning effort: the levels Claude Code accepts for the model (from low up to max), plus ultrathink on models that support it, which Coincide asks for in the prompt.
  • Fast mode: offered on models that report it. If Claude Code ran a turn at standard speed anyway, Coincide shows Claude Code’s reason, such as needing a paid plan or usage credits.
  • Custom models: add model IDs Claude Code accepts but doesn’t list in Settings › Claude Code.

What works with Claude Code

Plan modeClaude Code’s own plan mode. When Claude finishes a plan, Coincide shows it and Claude waits; if Claude enters plan mode by itself, you choose Implement or Keep planning.
Approvals and full accessAsk for approval uses Claude Code’s default permission mode. Full access uses bypassPermissions; if your Claude Code settings forbid that, Coincide falls back to auto mode, then to asking. “Always allow” lasts for the session.

SteeringA message sent while Claude works can steer the running turn instead of waiting for it.
AttachmentsImages (PNG, JPEG, GIF, WebP) and PDFs are sent to Claude; other files are mentioned by path.
SubagentsSubagents’ tool calls show as progress in the turn, and background work is tracked.
ResumingEach thread keeps its own Claude Code session. Coincide also names it after the thread, so claude --resume in Terminal shows the same titles.
Usage limitsYour plan’s session and weekly limits, read from Claude Code, in the composer and the usage dashboard.
ImportingEarlier Claude Code conversations can be imported from ~/.claude and continued.

Switching to and from Claude Code

Type /claude in the composer, or pick a Claude model, to hand a thread that another agent started to Claude Code. Claude gets a recap of the turns it missed and works in the same folder. Switch away and back again, and Claude Code resumes its own session with only the newer turns recapped. How switching works.

Limitations

  • Coincide uses the Claude Code you have installed, so new Claude Code features appear only once Coincide supports them, and some models need a recent Claude Code.
  • Changing some settings in the middle of a thread restarts Claude Code’s process, which stops its background work; Coincide tells you when that happens.
  • With a custom API endpoint (a non-Anthropic ANTHROPIC_BASE_URL), plan usage limits aren’t shown.
  • Claude Code’s own usage policies and plan limits apply as usual.
