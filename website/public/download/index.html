Download Coincide

Coincide is free and open source. It’s one universal app for Apple silicon and Intel Macs, signed with Developer ID and notarized by Apple. Pick the way you like to install apps.

System requirements

Requirement
macOSmacOS 26 or later
MacApple silicon or Intel (one universal app)
AgentsAt least one agent’s command-line tool, installed and signed in: Claude Code, Codex, Cursor, Grok Build, OpenCode or Antigravity
npm install onlyNode.js 18 or later

There’s no Coincide account to create and nothing to pay for. Your agents use your own plans or API keys with their providers.

Install from the DMG

  1. Download Coincide.dmg. The link always points to the latest release.
  2. Open it and drag Coincide to the Applications folder.
  3. Open Coincide from Applications. Because it came from the internet, macOS asks once whether to open it; it’s notarized, so it opens normally.

Install with Homebrew

brew install --cask apoorvdarshan/tap/coincide

The cask lives in the apoorvdarshan/homebrew-tap repository and is updated by every release. It’s marked as updating itself, so after installing, Coincide’s own updater keeps it current. Removing it with brew uninstall --cask coincide also stops Coincide’s background helpers; add --zap to delete its data too (see Uninstall).

Install with npm

npx coincide-dev

The coincide-dev package downloads the latest release from GitHub, checks its SHA-256 checksum against the release’s SHA256SUMS.txt, verifies Coincide’s Developer ID signature and notarization, and installs Coincide.app into /Applications. If Coincide is running, it asks before quitting it. It uses only Node’s own modules.

npx coincide-dev install 0.1.0         # a specific version
npx coincide-dev where                  # where Coincide is installed, and its version
npx coincide-dev --dir ~/Applications   # install somewhere else
npm install -g coincide-dev             # keep the command around as coincide-dev

Check the download

Each GitHub release lists the SHA-256 of its DMG and ZIP files in SHA256SUMS.txt. To compare yours, and to see Apple’s verdict on the installed app:

shasum -a 256 ~/Downloads/Coincide.dmg
spctl --assess --verbose /Applications/Coincide.app

spctl should report accepted with the source Notarized Developer ID. Releases are signed by Apoorv Darshan’s Developer ID (team 23RV7FYH36) and built in public by the repository’s release workflow.

Updates

Coincide checks GitHub for a new release once a day (Settings › About › Check for updates daily, on by default), and you can check any time with Coincide › Check for Updates. Nothing is installed without you: choose Download Update, then Install on Quit, and the update is verified and installed after you quit Coincide; then open it again. The previous version is kept as a backup. Updating Coincide covers the details, and the changelog lists what changed.

Uninstall

Turn off Keep Awake first if you use it (so your Mac’s sleep settings are restored), quit Coincide and move it to the Trash. Coincide’s data, background helpers and the coincide command are covered step by step in Uninstall Coincide.

Build from source

Coincide is MIT-licensed, and you can build it yourself with Xcode 27 and XcodeGen. See Build from source.
