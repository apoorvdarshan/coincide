Feature

The ⌘K command palette

Press ⌘K anywhere in Coincide’s window and type. The palette searches actions, threads, projects and settings together, and you never have to leave the keyboard.

Opening and moving around

View › Command Palette… opens it, with ⌘K by default (you can change the shortcut in Settings › Keyboard). It floats over the main window, never over other apps, and closes when you press Escape or click elsewhere. Arrow keys move through the results and Return runs one. Some items open a nested list; Escape steps back out of it before closing the palette.

What it lists

Before you type, it shows the most useful actions, your recent threads, and more actions below them. As you type, results are grouped into Actions, Threads, Projects and Settings, and the best-matching group comes first.

WhatExamples
ActionsNew Thread in a project, New Chat, New Bot…, Talk to a bot, Add Project…, Open in your editor, Show or Hide Terminal, Diff, Pull Requests or Browser Preview, Find in Thread…, Stop Agent, Pin, Rename or Archive Thread, Schedule a Message in This Thread…, Edit Instructions, Dictate, Change Appearance…, Refresh Agents, Open Settings
Composer controlsChoose Agent and Model…, Choose Reasoning Effort…, Choose Access…, Switch to Plan Mode or Build Mode, and Switch to each other ready agent
ThreadsEvery thread and chat, by title, with its branch and project counting a little toward the match
ProjectsEvery project, found by name or path; the New Thread in… list starts a thread in one
SettingsGeneral, Agent, Model, Voice and Keyboard settings, Global Instructions and About Coincide, found by keywords such as “whisper” or “keybindings”

Actions show their keyboard shortcut on the right, using yours if you changed it, so the palette is also a way to learn them.

Files and text in the thread’s folder

With a thread open, two nested lists work on its folder (its worktree or the project):

  • Go to File… finds files by name and opens the one you pick in the editor you chose for Open In.
  • Search in Project… finds text in the folder’s files, a few lines per file, and opens the file at the matching line when the editor supports it. It uses ripgrep when it’s installed with Homebrew, and grep otherwise, skipping .git and node_modules.

Adding a project by path

Type a path that starts with / or ~ and the palette lists folders there. Tab completes a folder so you can keep browsing, and choosing one adds it as a project.

How matching works

The palette’s search is forgiving but not vague:

  • Every word you type must start a word somewhere, so “sid” finds “Fix sidebar”.
  • Words typed together still match, so “vscode” finds “VS Code”.
  • When nothing matches exactly, one typo is allowed.
  • A match inside a word needs at least four letters and only counts in titles, so “del” doesn’t find “model”.
  • Case and accents are ignored, and among equally good matches, threads you used recently rank higher.

Palette or sidebar search?

The palette matches names: thread titles, projects, commands and settings. To find a thread by something said in it, use the sidebar’s search (⌥⌘F), which also looks through messages; inside a thread, ⌘F finds text in the transcript. See Projects and threads and the full list of shortcuts.
