Projects, threads and chats

Coincide’s sidebar holds every conversation you have with every agent. Threads belong to a project folder, chats stand on their own, and the inbox tools keep a busy list manageable.

Projects, threads and chats

  • A project is a folder on your Mac, usually a Git repository. Add one with File › Add Project… (⇧⌘O). Its threads run agents in that folder, or in a worktree of it.
  • A thread is one conversation in a project. File › New Thread (⌘N) starts one in the current project, File › New Thread in Project picks another, and hovering a project’s row in the sidebar shows its own New Thread button.
  • A chat is a conversation without a project, listed under its own Chats heading. File › New Chat (⇧⌘N) starts one. If you mostly use Coincide like a chat app, Settings › General › “New Thread starts a chat” makes ⌘N start a chat.

Bots have their own section at the top. A thread can move to another project with Move to Project in its context menu; its agents’ sessions in the old folder end, and running threads stay where they are.

Finding a thread

  • Search. The sidebar’s search field (Edit › Find › Search Threads, ⌥⌘F) matches thread titles and projects as you type, and after a short pause also searches every thread’s messages, showing the matching line.
  • Keyboard. ⌘1 to ⌘9 jump to the threads numbered in the sidebar (hold ⌘ to see the numbers), and ⇧⌘[ / ⇧⌘] go to the previous or next thread.
  • The palette. The command palette searches threads, projects and settings with typo tolerance.
  • Sorting. Projects, threads, chats and bots each have Sort By options (manual order, recent activity, name, and for threads date created), and Threads per Project can fit the list to the sidebar, show a fixed number or show all.

Keeping the list short

ActionWhat it doesHow
PinKeeps a thread at the top of its listThread › Pin Thread, ⇧⌘P
ArchiveMoves a thread out of the sidebar, keeping its historyThread › Archive Thread, ⌘W
SnoozeHides a thread until In 1 Hour, In 3 Hours, This Evening, Tomorrow or Next Week; it comes back at the topSnooze in the thread’s context menu
SettleHides a quiet thread until new activity arrives in itSettle in the thread’s context menu
Mark as UnreadPuts the unread dot backThe thread’s context menu

A snoozed or settled thread whose agent is working, or needs an approval or an answer, stays in view. The sidebar’s options menus have Show Archived Threads, Show Snoozed Threads and Show Settled Threads, and View › Archived Threads… (⌥⌘A) and Settings › Archive list everything archived. Settings › General can ask before archiving or deleting a thread.

Acting on several threads

Select several threads in the sidebar (⌘-click or Shift-click) to archive or unarchive, settle or unsettle, move or delete them together. Undo and Redo (⌘Z, ⇧⌘Z or the Edit menu) take back a whole batch during the current app session. Undo restores the conversations and their checkpoints; it doesn’t restart an agent or terminal command that was stopped.

Thread titles

With Settings › General › “Name threads with the agent” on, the thread’s own agent titles it from your first message and its first reply, using its quickest model. “Keep titles up to date” lets the agent check the title every few turns while you use the thread. Rename a thread yourself with ⌘R, and it keeps your name. Titling is a small request to the agent, so it counts toward that provider’s usage.

Project defaults

Project Defaults… in a project’s context menu sets the model, permissions (full access or approvals) and mode (plan or build) for new threads in that project. Turn on Use Global Defaults to follow Settings › General instead. Existing threads keep their own settings.

Fast with long histories

The sidebar loads from a small index, and a thread’s transcript is read only when you open it, so hundreds of threads don’t slow down launch. Everything is stored on your Mac; see Where data is stored.
