Feature

Diffs, checkpoints, fork and rewind

Coincide snapshots your working tree around every agent turn, so you can see exactly what a turn changed and undo it, whichever agent did the work. Git does the bookkeeping; your branches, index and stash are left alone.

The diff panel

View › Show Diff (⌘D) opens the diff beside the conversation, for the thread’s folder: its project checkout or its worktree. Its menu chooses what to show:

ScopeWhat it shows
Uncommitted ChangesEverything in the working tree that differs from the last commit, untracked files included
Branch ChangesEverything the current branch changed since it left its base branch
Latest TurnWhat the agent’s most recent turn changed, updating while the turn is still running
Turn 1, Turn 2, …Any earlier turn of the thread, with its time and the number of files it touched

The diff options switch between Unified Diff and Side-by-Side Diff, ignore whitespace, and collapse or expand every file. A file list shows each file as added, modified, deleted, renamed or untracked; from a file you can open it, copy its path or reveal it in Finder.

To ask for a change, select lines and choose Comment on Selected Lines…. Your comment goes to the composer as a card with those lines, so the agent knows exactly what you mean.

Checkpoints

With Settings › General › Git › “Create checkpoints” on (the default), Coincide snapshots the working tree before each turn and again when it ends. Each snapshot is a Git commit built in a temporary index and kept alive by a hidden ref under refs/coincide/checkpoints/. It never touches your index, branches or stash, and isn’t on any of your branches.

Checkpoints are what make per-turn diffs possible, for every agent. They need the folder to be a Git repository; for a folder that isn’t one, the diff panel offers Initialize Git.

Reverting a turn

On one of your earlier messages, choose Edit from here. Coincide asks “Edit from here?” and offers:

  • Revert and Keep Changes: the conversation is rewound to before that message, which comes back to the composer for you to edit and send again. Files stay as they are.
  • Revert Files Too: the same, and the working tree is also put back the way it was before that turn, undoing every edit since.

Revert Files Too is only offered when it’s safe. Restoring rewrites the whole folder, so Coincide refuses while another thread is working in the same folder, or has worked there since that turn. The checkpoints of the reverted turns are discarded, since that history no longer exists.

Forking a conversation

To try another direction without losing this one, choose Fork from this response on any reply, or Fork Thread in the sidebar for the conversation up to its latest finished turn. The fork is a new thread in the same project with the conversation so far, and opens with the cursor in its composer. A divider in each thread links to the other.

A fork, like a rewind, starts the agents’ native sessions afresh: the next agent gets a recap of the conversation it carries on, as when you switch agents. A fork shares the folder with its original unless you move it to a worktree, so both see the same files.

Committing

From the diff panel you can also commit, push, pull and open a pull request, with commit messages and descriptions an agent writes from your changes. That’s covered in Commits and pull requests.

Things to know

  • Checkpoints cover the thread’s folder. Changes an agent makes elsewhere on your Mac aren’t restored.
  • Turning checkpoints off stops new snapshots; the turn scopes then say “Turn checkpoints are off”.
  • Undoing an archive, move or delete in the sidebar never changes files. To undo an agent’s edits, revert a turn.
