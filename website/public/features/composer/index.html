Feature

The composer

The composer is where you talk to whichever agent runs the thread. It takes files and images, mentions files in your project, runs commands, and decides what happens when you send while the agent is still working.

Sending

Settings › General › “Send messages with” chooses Return (Shift-Return adds a line) or Command-Return (Return adds a line). In an empty composer, the Up arrow brings back your earlier messages in the thread, and Down walks back to your draft. Each thread keeps its own draft, attachments included, when you switch threads or restart Coincide. ⌘. stops the running turn.

Attachments

Paste or drop images into the composer, or click the attach button to choose images, PDFs or other files. Images are copied into Coincide’s attachments folder as PNG, JPEG, GIF or WebP, at most 2000 pixels on the long edge; click a thumbnail to see it in Quick Look. How the file reaches the agent depends on the agent:

AgentImagesOther files
Claude CodeSent inline (resized to fit Claude’s limits)PDFs are sent as documents, up to 100 pages or 20 MB; other files are named by path
CodexSent as local images, when the model accepts imagesNamed by path
CursorSent inline, or named by path if Cursor can’t take themNamed by path
Grok BuildPNG, JPEG, GIF and WebP up to 10 MB, inlineNamed by path
OpenCodeSent as file references with their pathNamed by path
AntigravityPNG, JPEG, WebP and BMPNamed by path

“Named by path” means the agent is told where the file is on your Mac and can open it with its own tools.

Quotes, terminal output and diff comments

Context you collect shows as cards beside the attachments:

  • Quotes. Select text in a reply, plan or message and click Reply, or press ⌘L (Edit › Add Selection to Composer).
  • Terminal output. Select text in the terminal and add it the same way, or press ⇧⌘L in the terminal to send the last command’s output.
  • Diff comments. In the diff, select lines and choose Comment on Selected Lines… to tell the agent what to do about them.

Cards stay attached through drafts and sending, and they’re included when another agent takes over the thread.

Mentions and commands

TypeWhat it offers
@Files and folders in the thread’s folder, from git ls-files (so .gitignore is respected) or a folder walk. Choosing a folder keeps the list open on its contents.
/Coincide’s commands: /model, /plan, /build, /usage-limits when the agent reports limits, and one per other ready agent, such as /codex. Below them, the current agent’s own slash commands.
$The current agent’s skills, when it reports any.
#Open pull requests of the repository on GitHub, mentioned as a link.

Tab or Return chooses the highlighted suggestion and Escape closes the list. A message that is only a Coincide command, such as /plan, changes the thread instead of being sent.

Sending while the agent works

Each thread has a follow-up behavior, chosen in its composer (new threads start with the one in Settings › General):

  • Steer sends your message into the running turn, so the agent adjusts course without stopping. Claude Code, Codex and OpenCode support this.
  • Queue holds the message until the turn ends. Queued messages show in a card where you can send one now, edit it or remove it.
  • Interrupt stops the turn and sends your message next.

The alternate send does the other thing for one message: ⌘↩ (or ⇧⌘↩ when Command-Return sends), or ⌘-click on the send button. For Cursor, Grok Build and Antigravity, which can’t take a message mid-turn, Steer is shown but queues instead.

The composer’s controls

Under the text are the thread’s settings: agent and model, reasoning effort, speed where offered, access, and plan or build mode. On the right are attach, the microphone for dictation, a meter of your plan’s usage limits for agents that report them, and a context-window meter showing how full the conversation is.
