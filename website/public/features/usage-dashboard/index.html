Feature

Usage dashboard

How much of your Claude plan is left this week? Is Codex close to its limit? Settings › Usage answers both for every agent you use, from the figures each provider reports, next to charts of what your agents did in Coincide. A menu bar item keeps the closest limit in view.

Plan limits and credits

For each signed-in agent account, Coincide shows the limits its provider reports, such as a 5-hour session window, a weekly limit or a monthly allowance, how much of each is used, and when it resets. A mark shows where even spending across the window would be, so you can tell whether you’re ahead of pace. Choose whether figures read as what’s used or what’s left.

Coincide reads these with the sign-in each agent already keeps on your Mac, and the credential goes only in a request header to that provider’s own address:

AgentWhere the figures come from
Claude CodeClaude Code itself: session and weekly limits, per-model weekly limits, monthly spend and extra usage, updated live as you work
CodexCodex itself, for ChatGPT sign-ins: plan limits, per-model limits and credits, updated live
CursorCursor’s usage service: monthly limits and dollar figures for included and on-demand usage. Off until you turn on “Show account usage” in Settings › Cursor, since it reads Cursor’s sign-in from your Keychain
Grok BuildxAI’s billing service for Grok sign-ins: the weekly, monthly or subscription window
OpenCodeOpenCode Go plan windows, with OpenCode’s own stored key
AntigravityGoogle’s Cloud Code service: Gemini and shared Claude & GPT windows, 5-hour and weekly

The same figures appear in the composer while you work, so you see a limit coming before a turn fails. Accounts that use an API key have no plan limits; for those, Coincide counts the tokens of the turns it runs.

Extra figures you can turn on

  • Anthropic API keys: on request, Coincide reads a key’s per-minute rate limits by sending a one-token message, which costs a fraction of a cent. If you add an Anthropic Admin API key, it reads your organization’s usage and cost reports from Anthropic.
  • Provider websites (off by default): “Use my browser sign-in for extra details” reads Codex credit details from chatgpt.com, your prepaid API credit balance from the Claude Console, and your OpenCode Zen balance from the OpenCode Console, with your sign-in in Coincide’s browser. These are the sites’ own internal pages, not public APIs, so they can stop working without notice; Coincide then says why.

Activity in Coincide

Below the limits, Settings › Usage charts the turns your agents ran, for today or the last 7, 30 or 90 days, for all agents or one:

  • tokens per day, split into input, output and cache reads and writes;
  • an estimated cost per day at the providers’ API list prices, labelled as an estimate, since subscription usage isn’t billed per token;
  • top models and top projects, turns, threads and active time.

“Include usage from outside Coincide” (on by default) also counts Claude Code and Codex sessions you ran in a terminal or another app, read from their own logs on your Mac. Coincide keeps the history of the latest 10,000 finished turns, on your Mac only.

Token counts and reported costs are shown with their scope. Coincide never adds them up into a bill: your provider’s invoice is the only billing total.

The menu bar item

With “Show usage in the menu bar” on (the default), Coincide’s menu bar item shows one figure: by default the agent you used last, with its most used limit or its credit balance. You can pin a specific account and limit instead, show the limit closest to running out across every account as a gauge, or add a second figure beside the first. Click it for every account’s limits and today’s usage.

How often it refreshes

Limits refresh automatically while you work, and on a schedule you can set, from every minute to every hour, or only when you open the dashboard. Claude Code and Codex also push updates during turns.

Privacy

None of this goes to us. Usage requests go from your Mac straight to each provider, and the history stays in Coincide’s data folder. The privacy policy lists every usage source.
