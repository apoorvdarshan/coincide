Feature

Drive Coincide from Terminal, scripts and agents

Coincide comes with a coincide command. Anything that can run a shell command, you in Terminal, a script or one of your agents, can use it to start threads on any agent, talk to them and wait for what they say.

Agents that hand work to other agents

Every agent Coincide starts can already run coincide, with no setup, and can call its own thread this. So a Claude Code thread can start a Codex chat to review its change, wait for the review and read it back, all in one turn:

coincide new --agent codex --wait "Review the diff in $(pwd) for bugs. Reply with a list."

The new chat shows up in your sidebar like any other, so you can open it, follow along or take over. This is different from switching agents inside one thread: here each agent keeps its own thread, and they work at the same time.

Scripts and shell habits

Because the tool waits for replies and returns meaningful exit codes, it fits into scripts:

  • pipe text in with - as the message, for example a failing test log;
  • use --wait to block until the agent answers, and --json to pick the reply apart with jq;
  • check the exit status: 3 means the thread is waiting for an approval or an answer, 4 that it timed out.
npm test 2>&1 | coincide send "Fix the failing test" --wait -
case $? in
  3) coincide status "Fix the failing test" ;;   # it needs you
  4) echo "still working" ;;
esac

(send names the thread by its title here; an ID or the start of one works too.)

Answering from anywhere

A thread that asks for approval doesn’t have to wait for you to come back to the window. coincide status shows what’s waiting, and approve, deny and answer respond, the same as the cards in the thread. coincide open brings the thread up in Coincide when you’d rather look first.

What it can and can’t do

  • It lists projects, agents with their models, and threads; starts chats or project threads with a chosen agent, model, effort, access and plan mode; sends, steers or queues messages; waits; reads replies; stops turns; answers approvals and questions; archives and opens threads.
  • It doesn’t change settings, edit files or reach other Macs. It talks only to the Coincide running on this Mac, through a private socket, and only while Settings › General › Command Line › Command-line control is on.
  • Coincide must be running. With the background agent host, turns keep going after you quit, but the command needs the app open to answer.

Every command, option and exit status is in the command-line reference.
