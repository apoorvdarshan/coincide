Feature

Notifications that know where you are

Agents take minutes, and you’ll be doing something else. Coincide tells you when a turn is done or an agent is waiting on you, and once you’ve seen the thread, the alert goes away.

What you’re told about

With Settings › General › Notifications › “Notify when Coincide is in the background” on (the default), Coincide posts a macOS notification for these events, unless you’re already looking at that thread:

NotificationWhen
Agent finishedA turn ends. The notification shows the opening line of the agent’s reply.
Agent failedA turn ends with an error, with the error’s text.
Agent needs approvalAn agent in a thread set to Ask for approval wants to run a command or edit a file.
Agent has a questionAn agent stopped to ask you something.
Your turn in the browserAn agent working in the thread’s browser needs you to sign in, pass a check or enter a code.
Agent is waiting to startAn agent is slow to start, which usually means macOS is asking for permission to access a folder and needs you at the Mac.

Each notification is titled with the thread’s name, says what happened and in which project, and plays the default sound. Clicking it opens the thread, with its browser for a browser request. Archived threads don’t notify.

macOS asks for permission the first time a notification is due, not at launch. If notifications are turned off for Coincide in System Settings › Notifications, the setting says so.

The Dock badge

Coincide’s Dock icon shows how many approvals are waiting across all threads, so a glance tells you whether any agent is blocked on you. Answer them in each thread; see Approvals and questions.

Even with Coincide closed

When you quit Coincide while agents are still working, the background agent host keeps them running and posts the same finished, failed, approval and question notifications itself. Clicking one opens Coincide on that thread.

One device at a time

Coincide sends each event to exactly one place, so you don’t get the same alert on your Mac and your phone:

  • If you’re using the Mac (any input in the last two minutes, screen unlocked and awake), the Mac gets it, even with a phone in front of you.
  • If the Mac is idle, locked or asleep and you’re using Coincide Remote on an iPhone or iPad, the alert appears there instead.
  • If neither is in use, a phone that turned on lock-screen alerts and was used in the last four hours gets one on its lock screen, through your own iCloud account; otherwise the Mac does.
  • The device that would show an alert stays quiet when the thread is already open on its screen.

Coincide Remote is coming soon to the App Store. Until it’s out, notifications go to your Mac. Lock-screen alerts also need a Mac build signed for iCloud; see the privacy policy for what such an alert contains.

Cleared once seen

Opening a thread clears what was posted about it everywhere: notifications on the Mac, including ones the agent host posted while Coincide was closed, alerts in Coincide Remote and lock-screen alerts. You won’t come back to a stack of alerts for things you’ve already read.

Turning them off

Turn off “Notify when Coincide is in the background” in Settings › General, or manage Coincide in System Settings › Notifications to change banner style, sounds or Focus behavior. Notifications are ordinary local macOS notifications; nothing about them is sent to us.
