Feature

Computer Use

With Computer Use on, an agent in any thread can list your Mac’s apps and windows, read a window’s controls, click, type, scroll and take screenshots. It works the same for every agent Coincide runs, and it’s off until you turn it on.

Turn it on

  1. Open Settings › Computer Use and turn on “Allow agents to use this Mac”.
  2. Grant the permissions the pane lists, Accessibility and Screen Recording, with its Grant Access and Open System Settings buttons, then come back to refresh their status.
  3. Ask an agent to do something in a Mac app, for example “Open Notes, start a note called Groceries with today’s list, and show me a screenshot.”

The permissions belong to Coincide itself, because Coincide runs the helper as its own child process. You grant them once, not once per agent, and you don’t have to set up an MCP server for any agent: every thread reaches Computer Use through a private connection Coincide gives it.

How it works

Coincide bundles Cua Driver, an open-source helper made by Cua AI (MIT license), and starts it only when an agent needs it. After about two idle minutes, or soon after every thread is done with it, the helper stops; the next request starts it again.

Coincide passes agents only a fixed set of the helper’s tools:

KindTools
Looklist apps and windows, read a window’s state and the desktop, verify a result, zoom into part of a screenshot
Actclick, double-click, right-click, set a control’s value, type text, press keys and shortcuts, scroll, drag, move the cursor, use a menu item, launch an app, move or resize a window, run several steps in a row

Browser control, arbitrary scripts, installing things and changing the helper’s own configuration aren’t available through Coincide. For websites, agents use the thread’s Coincide browser instead.

The agent’s cursor

With “Show agent cursor” on (the default), Coincide draws a cursor where the agent clicks and types, on whichever display it’s working on, so you can watch without losing your own pointer. Agents are told to work in the background where an app allows it, and to use foreground actions, which do move focus on your screen, only for the task you asked for.

One thread at a time

Several threads can have Computer Use, but only one controls the desktop at a time. Another thread that wants it waits until the first releases it. Settings › Computer Use › Activity shows which threads are using the Mac, with Stop Computer Use and Restart Computer Use buttons.

Privacy

  • Screenshots and window contents an agent reads go to that agent’s provider, as part of the conversation.
  • Cua Driver normally sends content-free telemetry to Cua AI and checks online for newer versions of itself. Coincide switches both off every time it starts the helper, so the helper sends nothing to Cua AI. It’s updated only when Coincide is.
  • The private connection is limited to its thread and carries a short-lived credential.

The privacy policy has the exact settings Coincide uses.

Using it safely

  • Turn it on for the job, off afterwards. Turning Computer Use off ends every agent’s access at once, and it also stops when Coincide quits.
  • Close what you don’t want seen. An agent may take screenshots of any window it works with. Close private documents and messages first.
  • Prefer approvals. Run threads that use Computer Use with Ask for approval rather than full access when the task touches anything important.
  • Treat screens as untrusted. Agents are told that window text and screenshots are content, not instructions, but a page or document can still try to mislead an agent. Watch what it does with the agent cursor on.
  • Stay nearby. Actions can change files, settings and messages in real apps, and there’s no undo for what another app does.

Limitations

  • Computer Use runs only while Coincide is open, unlike agent turns, which keep running in the background.
  • Agents act on what the helper can see through Accessibility and screenshots; apps that expose little to Accessibility are harder to operate.
