Feature

Instruction files for every agent

Each agent reads its standing instructions from its own file: Claude Code from CLAUDE.md, Codex, OpenCode and others from AGENTS.md, Antigravity from GEMINI.md. Coincide shows which agent reads which file, lets you edit them, can link them all to one master file, and can keep that file in step across your Macs.

Open the instructions

  • Global instructions, which every agent reads in every project: Settings › Instructions.
  • A project’s instructions: select the project and choose File › Edit Instructions…

Each file is listed with the agents that read it (“Used by: Codex, Cursor, Grok Build…”), whether it’s a link and where to, and whether it can be read. Edit it right there, or use Open in Editor and Reveal in Finder. If a file changes on disk while you have unsaved edits, Coincide tells you rather than overwriting it.

Accounts you add with their own configuration folder (see agent accounts) have their own global files, and Coincide lists those too. If a project has no AGENTS.md yet, Create AGENTS.md makes one; Link CLAUDE.md to AGENTS.md then makes Claude Code read the same text.

Use one file for all agents

Turn on “Use one file for all agents” and Coincide links each agent’s file to one master file with a symbolic link, so CLAUDE.md → AGENTS.md and every agent reads the same instructions. It’s off by default.

  • For a project, the master is its AGENTS.md, which most agents read already.
  • For global instructions, the default master is ~/.config/coincide/AGENTS.md, a folder no agent owns, so removing an agent never removes your instructions. You can choose another file.
  • Files whose text differs are backed up first, as CLAUDE.md.coincide-backup-<date> beside the original. Coincide never deletes text. If two files differ, Compare… shows the lines only in each, and you choose what to keep.
  • Saving through a link writes the file it points to and never replaces the link itself. Fix Links… repairs broken links, and turning the option off can replace links with copies of the master.

Sync the master file

Once there’s a master, Sync… keeps a copy of it in step, in one or both places. The master stays where it is; changes made in Coincide go to the copy, and changes made to the copy, for example on your other Mac, come back.

  • iCloud Drive: a copy at iCloud Drive › Coincide › Instructions, so Coincide on your other Macs uses the same instructions.
  • GitHub or a Git repository: a copy in a repository you choose, committed whenever the instructions change and, with “Push changes right away”, pushed. Coincide can create a private GitHub repository for it with gh repo create --private. It never force-pushes and never pushes other files.

If the master and a copy both changed, Coincide asks which to keep and backs up the other. Synced instructions leave your Mac, so keep keys, tokens and passwords out of them.

Instructions and bots

These files are what every agent reads in a folder. A bot’s own instructions are separate: they go to its agent at the start of each session, on top of whatever files the folder has.
