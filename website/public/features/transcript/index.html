Feature

A transcript that reads well

Coincide draws each conversation with native macOS text, not a web view. Replies stream in smoothly, long threads stay fast, and you can always tell which agent and model wrote what.

Replies in Markdown

Agents write GitHub-flavored Markdown, and Coincide renders it: headings, emphasis, links, lists with task items, block quotes, tables, rules and fenced code. Code blocks are syntax-highlighted for common languages, with Xcode’s colors, and have a copy button. A reply that is still streaming renders sensibly mid-block, and only the parts that changed are drawn again, so long replies don’t slow down as they grow.

By default replies are set in New York, Apple’s serif, with code and tables in the system fonts. Settings › General › Reply font switches to San Francisco, “Your messages” puts your own messages on the left or right, and View › Increase Font Size (⌘+), Decrease (⌘-) and Reset (⌘0) change the size of the transcript and the composer.

Who said it

  • The agent rail. A line runs down the left side of the transcript in the color of the agent doing the work, with the agent’s logo where it starts answering. When the next turn goes to another agent, the line blends into that agent’s color, so a thread several agents worked on shows who did what at a glance.
  • Labels. Each reply ends with the agent’s name in its color and the model that wrote it; in a bot’s conversation, the bot comes first.
  • Reasoning. Settings › General › Show reasoning includes the agent’s thinking when the model shares it.

Work logs that fold away

While an agent works, its turn opens with “Working for 12s”. When it finishes, that line becomes a “Worked for 2m 13s” toggle that folds the turn’s tool calls, reasoning and interim replies, leaving the answer in view. Expand a tool call to see its input and output: the command and what it printed, or the diff of a file it edited. Very long output is trimmed from the front, since the end of a log matters most. Below a message you steered into a running turn, “Continued for 20s” folds the work that followed it.

Approvals and questions also appear in the log, with their outcome; see Approvals and questions.

Images, media and previews

Agents can show more than text. Coincide renders, below the Markdown that refers to them:

  • images from absolute paths on your Mac or from the web;
  • audio and video with playback controls, which never autoplay;
  • inline previews of local .html and .svg files;
  • interactive charts and small tools from coincide-html and coincide-svg code blocks, which run in a sandbox with no network, logins, forms, downloads or access to the app;
  • images that Codex generates, copied into the thread’s attachments even when the reply doesn’t link them.

Previews wait until a reply has finished streaming, and up to eight are shown per reply. Rich agent output explains how agents (or you, in instructions) can use these.

Working with the transcript

  • Find. Edit › Find › Find… (⌘F) searches the thread, including rendered Markdown, tool-call titles and expanded output, and highlights each match.
  • Reply. Select text in a reply, plan or message and a Reply button appears; it puts the selection in the composer as a quote (⌘L does the same).
  • Copy. Copy a message, a whole response or a single code block.
  • Fork or rewind. “Fork from this response” starts a new thread with the conversation up to there, and “Edit from here” rewinds to one of your messages; see Diffs and checkpoints.
  • Links. A web link opens in the thread’s browser, and ⌘-click opens your default browser. Settings › General › “Open links in your default browser” swaps the two.

Fast with long histories

A transcript is read from disk only when you open its thread, so a long history doesn’t slow down launch or the sidebar. Agents’ messages and tool output stay on your Mac in Coincide’s data folder (see Where data is stored).
