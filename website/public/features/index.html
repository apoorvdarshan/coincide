Features

What Coincide adds to your agents

Coincide is a native Mac app built with AppKit. It runs the coding agents you already use and wraps them in the tools around the conversation: threads, git, a terminal and a browser per thread, schedules and bots.

Agents and threads

Run several agents in one window and move work between them.

  • Switch agents mid-threadHand a conversation to another agent; it gets a recap of the turns it missed and works in the same folder.
  • Model pickerEvery installed agent’s models in one searchable menu, with favorites, hidden models, reasoning effort and speed.
  • Projects and threadsA sidebar of projects, threads and chats with message search, pinning, archiving, snoozing and per-project defaults.
  • Command palettePress ⌘K to find threads, run actions, switch agents and models, open files and search your project’s text.
  • Plan modeHave the agent investigate and propose a plan without changing files, refine it, then implement it with one click.
  • Approvals and questionsLet agents run freely or approve each command and edit, per thread, and answer agents’ questions inline.
  • ComposerAttachments, @ file mentions, slash commands, quotes and diff comments, and steering or queueing while an agent works.
  • Native transcriptMarkdown, highlighted code, images, audio, video, sandboxed previews and folded work logs, labeled by agent and model.
  • Background agentsA background agent host keeps every turn running when you quit, update or crash Coincide.
  • NotificationsHear when an agent finishes, fails, needs approval or asks a question, on the one device you’re using.

Code and git

Review what agents changed, undo a turn and ship it.

  • Diffs and checkpointsSee what each turn changed, put files back the way they were before it, and fork or rewind the conversation.
  • WorktreesRun each thread in its own Git worktree and branch, so parallel agents never edit the same checkout.
  • Commits and pull requestsCommit, push and open pull requests on five Git hosts with agent-written messages; review GitHub PRs beside the chat.
  • Integrated terminalA terminal per thread in its folder or worktree, with tabs, up to four panes, and a key to send output to the agent.

The browser and your Mac

Let agents work in a real browser and, if you allow it, in other apps.

  • Browser in every threadA WebKit browser beside each conversation that agents can read, click and type in, with your sign-ins.
  • Passwords and loginsFill sign-ins from your Keychain, 1Password or Bitwarden, and let agents sign in without seeing passwords.
  • PasskeysSign in with Bitwarden passkeys in Coincide’s browser, or import a passkey sign-in from your own browser.
  • Computer UseAgents see and operate native Mac apps through a bundled helper, with their own cursor. Off by default.
  • AppshotsPress both ⌘ keys in any app to bring that window into a chat, ready for your question.
  • Keep AwakeKeep a MacBook running agents 24/7 with the lid closed, and restore your sleep settings afterwards.

Automation

Work that runs on a schedule, from a bot or from a script.

  • Scheduled tasksSend a prompt to a thread or start a fresh one on a schedule: daily, weekdays, intervals or cron.
  • BotsStanding assistants with a face, a personality and a job, on the agent and model you choose.
  • Command lineStart threads, send messages, wait for replies and answer approvals from Terminal, scripts or another agent.
  • Instruction filesEdit every agent’s instruction files in one place, use one master file for all agents, and sync it.

Everything else

  • DictationSpeak your prompts with Apple’s on-device speech, a local Whisper model, or OpenAI or Groq with your key.
  • Usage dashboardEvery agent’s plan limits and credits in one place, token activity charts and a menu bar gauge.
  • 19 languagesThe interface in 19 languages, following your Mac’s language or one you pick just for Coincide.
  • Coincide RemoteComing soon to the App Store: follow and steer your Mac’s agents from iPhone or iPad, connected directly to your Mac.
