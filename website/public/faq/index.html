FAQ

Frequently asked questions

Short answers, with links to the pages that go into detail.

Is Coincide free?

Yes. Coincide is free, with no paid tier, account or sign-up. You do need at least one coding agent, and those are billed by their providers under your own plans or API keys; Coincide never resells, proxies or meters their tokens.

Is Coincide open source?

Yes, under the MIT license. The source code, issues and releases are on GitHub. Coincide is a native AppKit port of T3 Code, which is also MIT-licensed.

Which coding agents does Coincide support?

Six: Claude Code, Codex, Cursor (its command-line agent), Grok Build, OpenCode and Antigravity. Coincide runs each one’s own command-line tool, so you need to install and sign in to at least one.

Do I need API keys?

No. Coincide uses the sign-in each agent’s tool already has, so a Claude or ChatGPT subscription, a Cursor plan or a Grok login works as it does in Terminal. API keys are optional: you can add them as extra accounts for an agent, and Coincide keeps them in your macOS Keychain. See Agent accounts.

Does Coincide send my code or conversations to a Coincide server?

No. There’s no Coincide server or account, and Coincide’s own code has no ads, analytics or tracking. Your agents send your messages, and what they read for you, to their own providers, as they would in Terminal. The privacy policy lists every connection the app makes.

Where does Coincide store my data?

On your Mac: projects, threads, settings and history in ~/Library/Application Support/Coincide, secrets in your login Keychain, and the browser’s data in ~/Library/WebKit. Where Coincide keeps its data lists every location.

Does Coincide run on Intel Macs?

Yes. Coincide is a universal app for Apple silicon and Intel Macs. It needs macOS 26 or later.

Which version of macOS do I need?

macOS 26 or later. Building it from source needs Xcode 27 or later.

How do I install Coincide?

Download the notarized Coincide.dmg, run brew install --cask apoorvdarshan/tap/coincide, or run npx coincide-dev. The download page explains each one.

How does Coincide update?

Coincide checks GitHub for a new release once a day (you can turn this off in Settings › About) and when you choose Coincide › Check for Updates. It downloads and installs an update only when you ask, and installs it after you quit. See Updating Coincide.

Can I switch agents in the middle of a conversation?

Yes. Type /codex, /claude or another agent’s command, or pick another agent’s model. The next agent gets a recap of the turns it missed and continues in the same folder; switch back, and the earlier agent resumes its own session. See Switching agents.

Do agents keep working after I quit Coincide?

Yes, by default. Agents run in Coincide’s background agent host, so a turn keeps going when you quit or update the app, and when you reopen it the reply is still there. See Agents that outlive the app.

Is it safe to give an agent full access?

Full access lets an agent run commands and change files without asking, which is fast but means you trust it with your project and your Mac. Choose Ask for approval in the composer to approve each command and file change instead. Either way, in a git repository Coincide creates a checkpoint before each turn (on by default), so you can revert a turn’s changes. See Approvals and full access.

Is there a Windows, Linux or Android version?

Not yet. Coincide is a native Mac app. Versions for Windows, Linux and Android are planned, each built natively; the “Not on a Mac?” buttons on the home page count how many people want each one.

Is there an iPhone or iPad app?

Coincide Remote, a companion for iPhone and iPad that connects directly to Coincide on your Mac, is coming soon. It hasn’t been released yet. See Coincide Remote.

What languages is Coincide available in?

19: English, Chinese (Simplified and Traditional), Dutch, French, German, Hindi, Indonesian, Italian, Japanese, Korean, Polish, Portuguese (Brazil), Russian, Spanish (Spain and Latin America), Turkish, Ukrainian and Vietnamese. The translations are machine-made and marked for review; corrections are welcome.

Can I use Antigravity safely with Coincide?

Google’s Antigravity terms restrict third-party tools, and Google has suspended accounts for it. Coincide shows a notice and asks you to acknowledge it before you sign in. Gemini API keys aren’t affected. Read the Antigravity page before using a Google subscription.

Is Coincide affiliated with Anthropic, OpenAI, Cursor, xAI or Google?

No. Coincide is an independent open-source project by Apoorv Darshan. The agents’ names and logos are trademarks of their owners and are used only to identify them.

How do I report a bug or ask for a feature?

Use the bug report or feature request forms on GitHub, or the /bug and /feature commands in the Coincide Discord, which need no GitHub account. Both become public GitHub issues. Report security problems privately through GitHub’s private vulnerability reporting.
