Coincide vs the Codex app

OpenAI’s Codex app now lives inside the ChatGPT desktop app, as a dedicated Codex view. Coincide runs Codex through the Codex CLI, next to five other agents. Here’s what each one does, according to its own documentation.

Updated November 1, 2026

OpenAI launched the Codex app for macOS in February 2026 and for Windows in March. According to OpenAI’s What’s new page, “On July 9, the Codex app merged into the ChatGPT desktop app for macOS and Windows,” where Codex keeps “its dedicated coding experience alongside ChatGPT’s Chat and Work.” This page compares that Codex experience with Coincide. Facts about OpenAI’s app come from its app page and the Codex docs linked below.

Codex only, or Codex among others

OpenAI’s app is built around Codex. Coincide treats Codex as one of six agents: its models sit in one picker with the others’, and a thread can switch from Codex to another agent and back, each keeping its own native session. When Coincide runs Codex, it starts codex app-server with your existing sign-in, so Codex’s plan mode, steering of a running turn, approvals and rate limits all come from Codex itself. Codex in Coincide has the specifics, including the CLI versions it supports.

Worktrees and parallel work

In OpenAI’s app, you choose a mode when you start a Codex chat: Local works in your project directory, Worktree isolates changes in a Git worktree, and Cloud starts a remote task. OpenAI’s worktree docs say Codex creates worktrees in $CODEX_HOME/worktrees, checks them out in a detached HEAD state rather than on a branch, and keeps your most recent 15 by default. Coincide’s worktrees are per thread: each one starts on a new branch, so you can commit, push and open a pull request from it. Coincide doesn’t run cloud tasks.

Reviewing changes

OpenAI’s review pane lets you attach inline comments to lines in the diff, stage or revert parts of the work, and commit or push; /review asks Codex for prioritized findings. In Coincide, diffs cover uncommitted changes, the branch and each turn, checkpoints revert a turn, and pull requests work on GitHub, GitLab, Bitbucket, Azure DevOps and Forgejo/Codeberg, with a GitHub PR workspace for checks and reviews.

Schedules, browser and the desktop

OpenAI’s app page says you can “create a standalone scheduled task or schedule a task inside an existing chat” and “use the browser, desktop apps, and plugins.” Coincide has scheduled tasks that send a message into a thread, or start a new one, while Coincide is open; a browser in every thread that agents can drive when you allow it; and Computer Use, off by default, for operating other Mac apps. These work the same whichever agent the thread uses.

Bringing Codex history along

Coincide can import conversations from the Codex CLI. File › Import CLI Session… lists local Codex and Claude Code histories, and an imported thread keeps its Codex session ID, so the next turn continues the same native session. See Importing CLI sessions.

When Codex in the ChatGPT app is the better choice

  • Codex is your only agent and you want OpenAI’s own app, with ChatGPT’s Chat and Work next to it.
  • You want cloud tasks, or to follow Codex chats from the ChatGPT mobile app.
  • You use Windows, or a Mac older than macOS 26.

When Coincide is the better choice

  • You use Codex together with Claude Code, Cursor, Grok Build, OpenCode or Antigravity, and want them in one window and one picker.
  • You want to hand a thread from one agent to another without re-explaining the task.
  • You want an open-source app that runs your agents only on your Mac.
