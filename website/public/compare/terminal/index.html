Coincide vs running agents in Terminal

Every agent Coincide supports is a command-line tool you can run yourself. Coincide doesn’t replace those tools: it starts the same CLI, with the same sign-in, and builds a Mac window around each conversation.

Updated November 1, 2026

If you already work with Claude Code, Codex, Cursor, Grok Build, OpenCode or Antigravity in a terminal, this page explains what changes when you run them through Coincide instead, and what doesn’t. Both approaches run the agents on your own Mac; the difference is what surrounds them.

At a glance

Agent CLIs in TerminalCoincide
What runs the agentThe CLI’s own interactive interfaceThe same CLI, through its machine interface: claude stream-json, codex app-server, cursor-agent acp, grok over ACP, opencode serve, and Antigravity’s ACP runtime
Sign-in and billingEach CLI’s own login or API keyThe same logins and keys. Coincide never proxies, resells or meters tokens
Several agents at onceOne per tab, window or tmux paneOne window, with projects, threads and chats in a sidebar
Changing agent mid-taskStart a new session and explain the work againSwitch in the same thread; the next agent gets a recap of the turns it missed
Reviewing changesgit diff and your own toolsDiffs for uncommitted changes, the branch and each turn, with per-turn checkpoints
After you close itThe agent stops with its terminal session, unless you use something like tmuxA background agent host keeps turns running after you quit Coincide
Where it runsWherever the CLI runs, including servers over SSHmacOS 26 or later, on Apple silicon or Intel

What stays the same

  • The CLI itself. Coincide looks for each agent on your login shell’s PATH and in the usual install folders (Homebrew, ~/.local/bin and others), or uses a path you set in Settings. You install and update the CLI the way its maker describes; each agent’s page lists the commands.
  • Your sign-in. If claude auth login, codex login, cursor-agent login, grok login or opencode auth login already worked in Terminal, Coincide uses that sign-in. Your subscription or API key stays with the provider.
  • The agents’ own files. The CLIs keep their configuration and history in their own folders, such as ~/.claude and ~/.codex, and Coincide doesn’t take them over. Extra sign-in accounts you add in Coincide get configuration folders of their own, so they don’t disturb your default login.
  • Where the work happens. Agents run on your Mac, in your project folder, with your tools on the path.

What Coincide adds

A place for every conversation

Each conversation is a thread inside a project, or a chat without one, kept in a searchable sidebar you can pin, archive and snooze. Projects and threads replace a row of terminal tabs, and the ⌘K command palette jumps between them.

One picker for every agent’s models

Models from every installed and signed-in agent appear in one menu, grouped by agent, with reasoning effort and fast mode where the provider offers them. Switching agents keeps each agent’s native session for the thread and hands the next one a recap, so you don’t paste context between tools.

Review without leaving the thread

Diffs and checkpoints show what each turn changed and let you revert it. Per-thread worktrees keep parallel work apart, and commits, pushes and pull requests can use agent-written messages. Approvals and agents’ questions appear in the thread, where you answer them, instead of as prompts in terminal scrollback.

Tools around the agent

Each thread has its own terminal and browser, which agents can drive when you allow it. Scheduled tasks send a message into a thread on a schedule while Coincide is open, and the usage dashboard shows your plans’ limits across agents.

Moving between the two

You don’t have to choose once. File › Import CLI Session… brings an existing Claude Code or Codex conversation into Coincide, keeping its session ID so it continues the same native session; the original file is left untouched. See Importing CLI sessions for the limits. For Claude Code threads, Coincide also names the native session after the thread, so claude --resume in Terminal shows the same title.

The bundled coincide command works the other way round: from Terminal or a script you can list threads, start one, send a message and wait for the reply. The command-line reference has the details.

When Terminal is the better choice

  • You work on a remote server over SSH, in a container or in CI. Coincide runs agents on the Mac it’s installed on.
  • You’re on Linux or Windows, or on a Mac older than macOS 26.
  • You rely on CLI options or interactive features that Coincide doesn’t expose in its composer and settings.
  • You want a single, short session and nothing else on screen.

When Coincide is the better choice

  • You use more than one agent, or want to try a different one partway through a task.
  • You keep many conversations going and want to find them again later.
  • You want to review diffs, approve commands and answer questions without reading terminal scrollback.
  • You want turns to keep running after you close the window.

Checked on November 1, 2026 against Coincide’s source code and README. The agent CLIs change often, so check their makers’ documentation for current options.
