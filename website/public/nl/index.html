Coincide downloaden

Gratis en open source · macOS

Al je codeeragents. Eén native Mac-app.

Coincide brengt Claude Code, Codex, Cursor, Grok Build, OpenCode en Antigravity samen in één venster. Elke agent gebruikt zijn eigen opdrachtregeltool met de aanmelding of API-sleutel die je al hebt, en je kunt midden in een thread van agent wisselen.

Download voor MacAlle installatiemogelijkheden

Vereist macOS 26 of nieuwer op een Mac met een Apple-chip of Intel-processor. Elke release is ondertekend met een Developer ID en door Apple genotariseerd, en Coincide werkt zichzelf bij.

Installeren via de opdrachtregel

Met Homebrew:

brew install --cask apoorvdarshan/tap/coincide

Met npm (Node.js 18 of nieuwer), dat de checksum, handtekening en notarisatie van de download controleert:

npx coincide-dev

Gebruik je eigen agents

Installeer minstens één agent en meld je aan. Coincide start de eigen tool van die agent op je Mac, dus je bestaande abonnementen blijven werken. Coincide verkoopt je tokens nooit door, stuurt ze niet via een proxy en meet ze niet.

Wat Coincide toevoegt

  • Midden in een thread van agent wisselenDe volgende agent krijgt een samenvatting van de beurten die hij heeft gemist en gaat verder in dezelfde map. Wissel je terug, dan hervat de eerste agent zijn eigen sessie.
  • Eén modelkiezerModellen van alle geïnstalleerde en aangemelde agents in één menu, met redeneerniveau en snelle modus waar de agent dat ondersteunt.
  • Projecten en threadsEen navigatiekolom met zoeken, vastzetten, archiveren en snoozen, en een opdrachtpalet met ⌘K.
  • Planmodus en goedkeuringenLaat een agent eerst een plan maken, keur elke opdracht en bestandswijziging goed, of geef hem volledige toegang.
  • Git ingebouwdDiffs, checkpoints voor elke beurt, worktrees, commits, pushes en pull requests.
  • Een browser in elke threadNaast de terminal in elke thread. Agents kunnen pagina’s openen, lezen en erdoorheen klikken als je dat toestaat.
  • Agents werken doorEen achtergrondproces houdt beurten gaande als je Coincide afsluit of bijwerkt.
  • Geplande taken en botsStuur elke werkdag om negen uur een prompt, of geef een bot een persoonlijkheid en een taak.
  • ComputerbedieningStandaard uit. Zet je het aan, dan kunnen agents andere Mac-apps bedienen met hun eigen cursor.
  • DicterenApples spraakherkenning op het apparaat, een lokaal Whisper-model, of je eigen OpenAI- of Groq-sleutel.
  • GebruiksoverzichtDe gebruikslimieten van je abonnementen per agent, met een lokale geschiedenis van recente beurten.
  • De opdracht coincideAgents en scripts kunnen vanuit Terminal threads aanmaken, berichten sturen en op antwoorden wachten.

Binnenkort: Coincide Remote

Een begeleidende app voor iPhone en iPad die rechtstreeks verbinding maakt met Coincide op je Mac, via je eigen netwerk of Tailscale. Hij is nog niet uitgebracht.
